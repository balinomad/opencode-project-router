# Code of Conduct

## Scope

This code of conduct applies to repository issues, pull requests, discussions, and other project spaces.

## Expected behavior

- Be respectful and direct.
- Assume good intent.
- Give technical criticism about code and behavior, not about people.
- Keep discussions focused on the project.
- Accept correction and update your position when the evidence changes.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without permission.
- Deliberate disruption of discussions or reviews.
- Repeated bad-faith argument after a decision is made.

## Reporting

Report unacceptable behavior to the maintainer through the contact information on the GitHub profile:

[https://github.com/balinomad](https://github.com/balinomad)

Do not use public issues for conduct reports.

## Enforcement

The maintainer may edit or remove content, close discussions, reject contributions, or block accounts for violations. Enforcement decisions are final.

## Attribution

This policy is a short project-specific code of conduct. It is not the Contributor Covenant.
